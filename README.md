# Ajo-saving-trackers-
Ajo saving trackers capstone project 
     Project Description

Ajo Saving Tracker is a simple project designed to help people manage and track their daily, weekly, or monthly Ajo savings.

Project Objectives

* To record savings contributions.
* To track the total amount saved.
* To help users monitor their savings progress.
* To improve savings management.

Features

* Recording savings.
* Tracking total contributions.
* Monitoring savings progress.

Technologies Used

* HTML
* CSS
* JavaScript

Conclusion

The Ajo Saving Tracker helps people organize their savings and monitor their financial progress.
